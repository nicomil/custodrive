Write to Windows disks from your Mac, with every copy verified.

Custodrive reads and writes NTFS disks and USB drives in a Finder-like window. Every file is read back from the disk and compared with the original before it appears.

Version · 1.4 MB · Apple Silicon · macOS 15.4+ · free and open source

Everything you need on an NTFS disk

macOS reads NTFS but cannot write to it. Custodrive adds the missing half, without drivers or kernel extensions.

Browse like in Finder

All external disks in the sidebar, sortable columns, clickable path, Back and Forward, and Quick Look with the space bar.

Verified copies

Drag files and whole folders from Finder. Each file is read back and checked with SHA-256 before it gets its final name.

Organize

New folder, rename in place, move by dragging or with ⌘X / ⌘V, and delete with a confirmation, since NTFS has no Trash.

Large copies, under control

Batches of up to 1000 files or 8 GB, one progress bar with speed and time remaining, a queue, and a Cancel that leaves the disk clean.

One password per session

Start editing once: the disk stays reserved for Custodrive until you finish, and every change is checked again.

English, Italian, Spanish

Choose the language from the globe menu in the toolbar. Copy to the disk also from Finder's Services menu or the Dock icon.

A closer look

Read-only until you choose to edit, and always clear about what is happening.

How it protects your data

Measures to detect errors and limit damage, tested with simulated interruptions and real USB unplugs.

Marked “needs checking” before every change, cleared only when the operation is complete and verified.

Nothing overwritten in place. New files are written apart and read back; a replaced file is kept until the new one is in place.

A recovery journal for replacements, moves, renames and new folders. If anything is ambiguous, recovery is refused and what is found is preserved.

Unsafe disks refused, such as disks left by Windows hibernation or Fast Startup, with an explanation.

System files protected: $MFT, System Volume Information, links and encrypted files are never modified.

An interruption, such as unplugging the disk during a copy, can still damage the filesystem: after it, run a Windows check. Keep a backup of important data.

Install

Custodrive is not signed with an Apple Developer certificate, so macOS asks for confirmation the first time.

Download for Mac
  1. Open Custodrive.dmg and drag Custodrive to Applications.
  2. Open Custodrive. macOS says the developer cannot be verified: dismiss the alert.
  3. Go to System Settings → Privacy & Security and click Open Anyway next to “Custodrive”. Needed only once per Mac.

Or, in Terminal:

xattr -dr com.apple.quarantine /Applications/Custodrive.app

Requirements and limits

  • Apple Silicon Mac (M1 or later), macOS 15.4 or later.
  • External NTFS disks and USB drives. Use Finder for APFS, exFAT and FAT.
  • Changes happen inside Custodrive: Finder keeps seeing the disk read-only.
  • Files are not edited in place on the disk: copy, replace or move them instead.
  • Compressed or encrypted NTFS files are not written.
